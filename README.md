## Why a separate repo?

The main Swock repository is **private** to protect proprietary source code. Google Play Console
requires the privacy policy and terms of service to be hosted at a **publicly accessible URL**.
This repo contains only the legal documents and the Swock logo — no source code.

## Update process

When the privacy policy or terms of service change:

1. Update the document in this repo
2. Update the "Last updated" date
3. Commit and push
4. Update the copy in the main repo's `docs/` folder to match
